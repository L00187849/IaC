# Python Automation and Scripting

## Description
This folder contains Python laboratory exercises and project work completed as part of the *Infrastructure as Code* module. The focus of this work is to develop core Python scripting skills for cloud, systems, and network automation. The scripts demonstrate foundational and intermediate Python concepts including variables, data types, control flow, loops, functions, modules, packages, file handling, error handling, logging, networking, and object-oriented programming.  

The work follows best practices in documentation, modular design, and testing, and aligns with Python Enhancement Proposals (PEP 8 and PEP 257). Supporting academic reports and screenshots are used to verify execution, outputs, and learning outcomes.

---

## Contents

### Python Scripts
- **Variables and Types** – Demonstrates variable assignment, casting, and basic arithmetic operations.  
- **Conditionals** – Uses `if`, `elif`, and `else` statements to control program flow.  
- **Loops** – Implements `for` and `while` loops, including `break`, `continue`, and `pass`.  
- **Functions** – Defines reusable functions with parameters, return values, and type hints.  
- **Lambda and Map** – Applies functional programming concepts for concise data processing.  
- **Modules** – Separates reusable logic into importable Python modules.  
- **Packages** – Organises modules into structured packages using `__init__.py`.  
- **Path Handling** – Uses `pathlib` to manage file system paths safely and portably.  
- **File Handling** – Reads from and writes to files using context managers (`with`).  
- **Error Handling** – Implements `try`, `except`, `else`, and `finally` blocks for robustness.  
- **Logging** – Uses Python’s logging library to record system and data logs.  
- **Networking (UDP/TCP/FTP)** – Demonstrates basic client/server communication and file transfer.  
- **Object-Oriented Programming** – Builds classes, inheritance hierarchies, and abstract base classes.  
- **Unit Testing** – Uses Python’s built-in `unittest` framework for automated testing.  

### Supporting Material
- **Screenshots** – Evidence of script execution and output.  
- **Settings Files** – External configuration files used for networking and system utilities.  
- **Templates** – Standardised headers and starter files for consistent development.

## Dependencies
- Python 3.10+  
- Visual Studio Code with Python extension  
- Git and GitHub  
- Windows 10/11 or Linux (tested on both)  
- Optional libraries (installed as required):
  - `psutil`
  - `ntplib`
  - `pyftpdlib`
  - `pylint`

## Testing Strategy
- Scripts are tested using:
  - Direct execution
  - `__main__` design pattern
  - Unit tests (`unittest`)
  - Static analysis using **pylint**
- Outputs are verified via terminal output, log files, and CSV data where applicable.
