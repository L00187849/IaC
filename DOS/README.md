# Week 5 – Infrastructure as Code

## Description
This folder contains the Week 5 lab work for the Infrastructure as Code module. The focus of this week was to develop an understanding of DOS-based automation by creating, customising and testing eleven batch scripts. These scripts demonstrate key automation concepts such as environment variables, conditional logic, loops, user input, error handling and output redirection. A formal lab report accompanies the scripts, documenting the method, results and analysis.

---

## Contents

### Batch Files
- **Demo1.bat** – Clears the screen and prints formatted output.  
- **Demo2.bat** – Displays the current working directory and lists its contents.  
- **Demo3.bat** – Creates new LabReports, BatchFiles and Screenshots directories.  
- **Demo4.bat** – Shows system date and time using environment variables.  
- **Demo5.bat** – Prompts the user for input and stores it as a variable.  
- **Demo6.bat** – Demonstrates pause and user-interrupt behaviour.  
- **Demo7.bat** – Checks if a specified file exists.  
- **Demo8.bat** – Demonstrates error handling using the `%ERRORLEVEL%` variable.  
- **Demo9.bat** – Uses `&&` and `||` to demonstrate success/failure logic.  
- **Demo10.bat** – Redirects command output and generates a log file.  
- **Demo11.bat** – Uses `FOR` loops to iterate through files and directories.

### Lab Report
- **Week5_Lab_Report.pdf** – Full report including method, results, figures and conclusions.
