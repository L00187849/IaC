\# Infrastructure as Code (IaC)

\-\--

\## Description

This repository contains coursework, lab documentation, for the
Infastructure as Code module as part of the \*\*PG Dip in Cloud
Technologies\*\* at \*\*ATU Letterkenny\*\*. It demonstrates
Infrastructure as Code (IaC) principles using virtualisation,
configuration management, scripting in both Windows and Linux
environments.
