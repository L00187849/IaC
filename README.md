\# Infrastructure as Code (IaC)

\-\--

\## Description

This repository contains coursework and lab documentation for the
\*\*Infrastructure as Code\*\* module as part of the \*\*PG Dip in Cloud
Technologies\*\* at \*\*ATU Letterkenny\*\*. It demonstrates
Infrastructure as Code (IaC) principles using virtualisation,
configuration management, and scripting in both Windows and Linux
environments.
