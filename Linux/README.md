# Week6

---

## Description

This repository contains coursework for **Week6**. It focuses on learning and practising Linux automation through personalised Bash scripts, executed on an Ubuntu server instance. The work includes creating, modifying and running shell scripts, understanding permissions, execution paths, file structures and encoding differences between Windows and Linux. All scripts have been adapted from the module notes to meet the Week 6 laboratory requirements.

---

## Contents

- **Linux Scripts**  
  - A dedicated `Linux` folder has been created in the `IaC` repository to store all Week 6 automation work.  
  - Personalised Bash scripts have been created based on the examples from the Automating Linux notes, including:  
    - **`welcome.sh`** – Outputs a custom welcome message and session details.  
    - **`system_report.sh`** – Generates basic system information.  
    - **`backup_directory.sh`** – Creates a timestamped backup of a chosen directory.  
  - All scripts were adapted with personalised names, dates, comments and behaviour.  


- **Lab Requirements Completed**  
  - Connected to the Linux VM using SSH (PuTTY) and configured file transfers using WinSCP.  
  - Practised core Linux commands such as navigation, permissions, directory management and editing with nano.  
  - Corrected script permissions using `chmod` and executed scripts using `./scriptname.sh`.  
  - Ensured correct encoding when moving files between Windows and Linux environments.  
  - Uploaded all completed work to the `Linux` folder in the `IaC` GitHub repository.

---

## Dependencies

- Access to an Ubuntu Linux instance through Azure Labs or VMware Workstation.  
- SSH client such as **PuTTY** and file transfer tool such as **WinSCP**.  
- Git installed locally or GitHub Desktop for version control.  
- A text editor such as **nano**, **Notepad++**, or **Visual Studio Code**.  
- Basic Linux utilities including `bash`, `chmod`, `who`, and standard GNU tools.
