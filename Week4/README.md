# Week 4

## Description

This section outlines the expectations and tasks for Week 4 of the
module. The focus is on developing academic writing skills, installing
essential tools on both the Windows host and Linux VM, and preparing a
structured laboratory report. The goal is to ensure seamless workflow
between environments and prepare for upcoming scripting and coding
tasks.

## Contents

### Academic Writing & Report Preparation

- Review academic report notes and download the provided template.\
- Document all Week 4 tasks in an academic-style laboratory report.

### Host Machine Setup

Install the following tools on your Windows host: - Python (latest
version, added to PATH) - Visual Studio Code (VSC) - Git & GitHub
Desktop (sync Week 2 & Week 3) - Notepad++ - PuTTY - WinSCP

### Linux VM Setup (ub2404-Development1)

Using the RDP-accessed VM: - Install/verify Python (added to PATH) -
Install OpenSSH Server - Install Git & GitHub Desktop - Install GitHub
CLI (`gh auth login`) - Install Visual Studio Code - Link the repo to
GitHub Desktop and sync Week 1 & Week 2 locally - Test connectivity from
host to VM using SSH and WinSCP

### Final Steps

- Keep full records of all work in a formal lab report.
- Create a **Week 4** folder in your repo and upload the PDF of your
  report.
- Submit the GitHub link through Blackboard.

## Dependencies

- Windows host environment\
- Ubuntu VM (ub2404-Development1)\
- RDP access\
- GitHub repository\
- Internet connection for installing required tools
